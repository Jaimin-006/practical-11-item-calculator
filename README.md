# Practical 11: Interactive E-Commerce Product Quantity & Price Calculator

## Unit Covered
Unit 3: Event Handling & Synthetic Events

## Key Concepts
Synthetic Events (onClick), Event Object (e.target), Common Mouse Events, Dynamic Calculation

## Problem Definition
Build an interactive e-commerce item component where users can select product sizes and adjust item quantities using buttons. The UI should instantly update total cost and log event details using synthetic events without complex JavaScript.

## How to Run
```bash
npm install
npm run dev
```
